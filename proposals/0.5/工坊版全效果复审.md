# 《杀戮尖塔2：盟约》0.5.0 全效果复审

基准是工坊发布版、原版 v0.113.1、六角色全卡池。核对了 35 个盟约的门槛、基础、进阶和里程碑，以及 717 张牌的原版与盟约效果，含基础和升级两版。卡牌数据与原生导出按类名对齐，涉及跨牌堆、自动打出和持续状态的候选回查了实现。本文是机制审查和设计稿，强度判断待跑图验证。社区视频和攻略作为打法与梗的出处，发布时间和游戏版本各异。

后续核对了原版箭矢机制。其他角色在第一张发射牌进入战斗牌堆时自动获得一支箭。松脱取回原箭，箭袋／箭袋+ 分别额外加一个／两个可复用箭位。

基础版与升级版各有 812 条执行规则。基础版其中 578 条是直接增层，162 条是数值修正，27 条是手写重做入口。多条规则可实现同一个特性，不能据此推断一张卡有几个独立效果。04/05 旧稿里的层数单位和门槛已经变化，以下按当前规则判断。建议允许成型后少数组合打出夸张结果，优先处理太早启动、能不推进战斗直接攒跨战层数、以及显示已激活却没有原生资源可用的情况。

## 一、平衡调整候选

### 优先看这些组合

| 高 | 飞刃 · 刀刃之舞、小刀、无尽刀刃、刀刃陷阱 | 生成的小刀本身可以补张数，且消耗堆仍计数。刀刃之舞产的小刀每张可加 3 层，来源升级且小刀也升级时为 5 层。三把基础小刀在盟约生效时合计 9 层，再同时吃飞刃补牌、零界和余烬。保留同一批小刀的输出，先降低基础来源的重复叠层。刀扇和刀刃陷阱的条件更鲜明，可以保留较高收益。 |

## 二、优先补的联动

| 联动 | 可以落到哪张牌或哪个时机 |
| --- | --- |
| 游弋与跨角色搭配 | 原版已经给其他角色的第一张发射牌配箭。适合补的是一支箭射出后的路线选择，可以用搭箭预支一次命中来推进扎穿，也可以用箭袋增加同时留在敌人身上的箭。 |
| 役骨与非死灵开局 | 检查跨角色使用护卫的原生召唤路径。选一张全卡池可见、写清「召唤」的普通支点，例如唤起。只有先召出奥斯提才谈得上戳击、攻击回合和役骨 II。碎骨可把下一次召唤变成返场的低费窗口，牺牲则继续奖励真正投入过生命值的奥斯提。 |
| 东尼 × 坚守 | 在巨像或究极防御上给一个可主动调到 16 的机会。例如打出后若格挡在 17–19，允许放弃多出来的格挡，使回合结束能够触发东尼。稳定保留精确 16 与连续减费，两个盟约各做自己擅长的事。 |
| 重装 × 刷免费牌 | 暂时免费、奇巧、自动出牌目前容易让高原始费用和实际付费关联脱钩。可给王者之踢或人工合成一个不同出口。手动把重牌降费后，按省下的能量给下一张原始重牌保留或加挡，重装的公共返费继续要求实际支付。 |
| 铸王 × 星辉 | 淬炼刀刃提供的延迟能量目前要被用于君王之剑才成长，铸剑者本身又要求星。可让战火铸就在本回合第二次锻造时，把一小部分铸造量暂存给下次真正消耗蓝星的牌，加固花星与锻造的往返。另一路给流光溢彩，低星时留下下一回合的防守节奏。 |
| 毒棘 × 巧变 | 蛇咬若被主动弃置，可以把少量本应施加的毒留给本回合下一次对敌攻击。蜃景用已经兑现过的中毒伤害做防御，毒雾、触媒照旧负责发作。这样的交叉不会要求毒猎额外抓三张做同一件事的牌。 |
| 幽逝 × 余烬 × 残响 | 虚空用回合结束的虚无消耗，内核加速来自真实扣掉的能量，下回合退款。可选强撑、压缩或净化之一，把一张状态的虚无消耗结果接到下一张真正打出的技能上。保持来源身份，避免把敌人塞的所有虚空都改成无偿产能。 |
| 咒缚 × 自伤与主动消耗 | 笨拙、愚行、进阶之灾可给「被咒缚自动消耗」一条等价通路，保留本来让它们处理掉时才兑现的个性。凡庸适合让玩家主动留下，完成第三次出牌才拿回报。悔恨可以把部分血换来的价值留给血誓的下一张攻击。 |
| 残响 × 造物 | 碰撞轨迹已经是好的桥，碎屑能提供两侧层数。迫降的主要特性目前偏独行固定加伤，可以改为第一个碎屑被处理时，给本轮下一张生成牌可见的费用或保留收益。让碎屑自身的正式状态牌身份继续生效。 |
| 逐利 × 奇遇/远见 | 逐利需要更多与是否拿这张牌有关的理由。劫掠或金斧选一张做小额获得金币，炼制药水的满药栏分支可给予金币之外的商店选项。远见重置与逐利兑换可以做成可见的经济决策，不用恢复锁一张。探寻和富足适合保留事件链，继续拿事件路线作为机会成本。 |
| 延续 × 幻影之刃/清淤 | 幻影之刃目前依赖别人给脆弱的临时小刀保留，发育中经常没有对象。给斗篷与匕首产的第一把小刀保留，或让清淤在取回已保留的小刀时能延续它原有加伤。保留手牌位代价，不把这一效果发给所有小刀。 |
| 造物 × 合奏 × 悲欢 | 说笑生成的悲伤若由旋律牌转成喜悦，可给下一张双旋律牌一点过渡。合奏已有传下回合旋律的强效果，把新触发放在「由此牌生成的悲伤」这一个来源上，避免倦怠、狂喜和所有喜悦互相重复触发。 |

### 值得独立确认的口径

- 既定事项原版升级后检索 3 张，盟约描述仍说「两张」。当前减费处理会遍历规则捕捉到的返回牌。实测应核对第 3 张也正确接到了特性，再统一为「由此放入手牌的牌」。
- 延续 II 用「直到打出」减费，每个回合可以再次选择仍被保留的同一张牌。确认是否有意允许重复积攒减费和待释放强化。若希望策略在于空出手牌，可让同一张牌可加强但未打出前只保留最新的一份减费。
- 星辉的 1 颗次回合偿还要求当回合第一次实际花费就把星耗尽，星辉 II 的回收则可由本回合后一次耗尽触发。测试「先花一部分再耗尽」与「第一次就耗尽」，避免把两条理解成同一触发。
- 调和只认熵。熵特性目前按普通层数档位加格挡，而调和没有普通层数档位。熵未升级和升级的固定值实际分别是 3 和 4。若要给第二张熵收益，明确按 I／II 的进牌堆状态走，或者直接强化变化后的第一张衍生牌。
- 全卡池奖励已有 35% 的同稀有度流派替换入口，先看其对早亮流派的反馈。稀有支点不足时，更有针对性的方式是让过渡牌补资源或给某个冷门组件少量奖励。
- 999 层是当前普通盟约全局上限。若要继续降低硬限制，建议先把零界返费、厄兆百分比和能滚层的来源各自拆开看。举例来说，纯伤害随层数继续长，与一整场可在敌人不行动时持续永久增层，是不同的风险。
